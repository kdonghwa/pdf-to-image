# PDF to Image Converter (PDF 이미지 변환기)

PDF 파일을 업로드하면 페이지별 이미지(PNG)로 변환해주는 무료 웹 도구입니다.
서버로 파일을 전송하지 않고 브라우저에서 안전하게 처리됩니다.

🔗 **데모 사이트:** [https://kdonghwa.github.io/pdf-to-image/](https://kdonghwa.github.io/pdf-to-image/)

## ✨ 주요 기능

- **PDF → 이미지 변환**: PDF의 각 페이지를 고화질 PNG 이미지로 변환합니다.
- **보안 강화 (Client-side Processing)**: 모든 변환 과정이 사용자의 브라우저 내에서 이루어지며, 서버로 파일이 전송되거나 저장되지 않습니다.
- **다국어 지원**: 한국어, 영어, 중국어, 일본어, 스페인어를 지원합니다.
- **일괄 다운로드**: 변환된 모든 이미지를 ZIP 파일로 한 번에 다운로드할 수 있습니다.
- **개별 다운로드**: 원하는 페이지만 선택하여 다운로드할 수 있습니다.
- **반응형 디자인**: PC와 모바일 환경 모두에 최적화되어 있습니다.

## 🛠 사용 기술

- **HTML5 / CSS3 / JavaScript**
- **[PDF.js](https://mozilla.github.io/pdf.js/)**: PDF 렌더링 및 페이지 추출
- **[JSZip](https://stuk.github.io/jszip/)**: 이미지 일괄 압축 및 다운로드

## 🚀 사용 방법

1. 웹사이트에 접속합니다.
2. 우측 상단에서 언어를 선택합니다 (기본값: 브라우저 언어).
3. 변환할 PDF 파일을 드래그 앤 드롭하거나 클릭하여 선택합니다.
4. 변환이 완료되면 리스트에서 이미지를 확인합니다.
5. 개별 이미지를 클릭하여 다운로드하거나, 하단의 **'📦 전체 ZIP 다운로드'** 버튼을 눌러 일괄 저장합니다.

## ⚠️ 주의사항

- 최대 **50MB** 이하의 PDF 파일만 지원합니다.
- 최대 **200페이지**까지만 변환이 가능합니다.
- 브라우저 성능에 따라 변환 속도가 달라질 수 있습니다.
